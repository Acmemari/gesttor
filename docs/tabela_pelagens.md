# Tabela de Pelagens

| Pelagem | Descrição |
|---------|-----------|
| Alazã | Corpo avermelhado, com crina e cauda geralmente da mesma cor ou mais claras. |
| Castanha | Corpo marrom/vermelho com crina, cauda e extremidades pretas. Pode ser castanha clara ou castanha escura. |
| Preta | Corpo, crina e cauda pretos. |
| Tordilha | Nasce escura e vai clareando com a idade, podendo ficar quase branca. |
| Baia | Tom amarelo-claro, creme ou dourado, geralmente com crina, cauda e extremidades escuras. |
| Lobuna | Tom acinzentado ou amarronzado, geralmente com crina e cauda escuras. |
| Rosilha | Mistura de pelos brancos com pelos coloridos, sem clarear tanto com a idade. |
| Pampa | Pelagem com grandes manchas brancas e coloridas. |
| Tobiana | Tipo de pampa, com manchas grandes e bem distribuídas. |
| Oveira | Manchas brancas irregulares, geralmente sem cruzar totalmente o dorso. |
| Apalusa | Pelagem com pintas, manchas ou salpicados, comum na raça Appaloosa. |
| Gateada | Tom amarelado ou acastanhado, muitas vezes com listra dorsal. |
| Zaina | Castanha escura, quase preta, geralmente sem marcas brancas. |
| Ruã | Mistura uniforme de pelos brancos com outra cor. |
| Isabel | Corpo creme/dourado claro, crina e cauda claras. |
| Palomina | Corpo dourado com crina e cauda brancas ou bem claras. |
| Cremela | Pelagem creme muito clara. |
| Perlina | Parecida com cremela, mas com tom levemente mais escuro ou perolado. |
| Branca | Pelagem branca predominante. Em equinos, pode ser confundida com tordilha muito clara. |
| Cinza | Pelagem acinzentada. No caso de bovinos, é a 'branca' comum do Nelore; pode ser dividida em cinza clara e cinza escura. |
| Vermelha | Pelagem de tom vermelho ou avermelhado. |
| Amarela | Pelagem amarelada, podendo variar do amarelo mais vivo ao tom palha. |

> **Observação:** Lista consolidada para uso em cadastro de animais; pode ser adaptada por espécie, raça ou padrão regional.
