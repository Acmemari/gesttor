Safra derivada da data

A safra é o período de 1º de julho a 30 de junho. Em vez de o usuário escolher a safra, ela é calculada automaticamente a partir da data lançada — então o campo deixa de ser entrada e vira informação. Cinco formas de apresentar isso:

Regra: data 04/06/2026 (junho) → safra 2025/2026 · data 15/08/2026 (agosto) → safra 2026/2027
Opção 1 · recomendada

Safra como legenda abaixo da data

Um único campo (Data). A safra aparece como texto auxiliar logo abaixo, atualizando sozinha. Menos campos, foco no que se digita.
Data
04/06/2026
Safra 2025/2026
+ Mais limpo · + 1 campo só · deixa claro que é derivado
Opção 2

Chip de safra dentro do campo

A safra vira uma etiqueta dentro do próprio campo de data, à direita. Compacto e sempre visível ao digitar.
Data
04/06/2026 Safra 2025/2026
+ Ocupa zero espaço extra · ótimo em telas estreitas
Opção 3

Legenda contextual acima

Uma linha discreta acima do campo anuncia a safra do período. Bom quando a safra contextualiza toda a tela, não só a data.
Safra 2025/2026
Data
04/06/2026
+ Safra ganha destaque de cabeçalho do lançamento
Opção 4

Dois campos, safra travada

Mantém o layout atual (Safra + Data lado a lado), mas o campo Safra fica travado e marcado como “auto”, preenchido pela data.
Safra
auto2025/2026 🔒
Data
04/06/2026
+ Menor mudança visual · mantém o hábito atual
Opção 5

Bloco unificado data + safra

Data e safra moram num único bloco em duas linhas: a data em cima (editável) e a safra derivada num rodapé sombreado.
04/06/2026
Safra 2025/2026 · jul/2025 → jun/2026
+ Mostra o período completo · vínculo data↔safra explícito
